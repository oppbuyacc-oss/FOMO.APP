# Fomo Mobile Terminal V19

## V19 changes
- Original FOMO mark extracted from the supplied screenshot is used in the mobile header, center navigation slot, green navigation badge, browser favicon, and app/home-screen icon.
- The bottom bar now uses the screenshot-style five-button layout: active Home with a frosted blue glass halo, outline Search, original logo mark, outline Traders/People, and the green logo button. Its pill has layered translucency, backdrop blur, a soft horizontal sheen, blue glow at the left and a subtle warm reflection at the right.
- Desktop three-column terminal and existing account/trading logic are retained.

## Run / add to home screen
1. Extract the complete ZIP so the HTML and icon/manifest files remain together.
2. Open the HTML in a browser, or host the folder over HTTPS.
3. On iPhone, open the hosted page in Safari and choose Share → Add to Home Screen. The included `fomo-touch-icon.png` supplies the home-screen icon.

Prices are locally generated for this standalone terminal and trades update the local account, not a live exchange.
